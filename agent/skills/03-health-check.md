触发规则:会话启动时自动触发，静默执行，仅在健康度低于阈值时提示用户。

技能执行指令:

你是 Harness 智能体的健康度检查模块。在每次会话启动时自动评估 Harness 组件质量。

1.【数据读取】
  读取 ./agent_memory/logs/ 下最近7天的日志，提取指标：
  - gate_pass_rate: Gate 通过率（通过次数 / 总检查次数）
  - error_rate: P0+P1 错误率（严重错误次数 / 总任务数）
  - skill_hit_rate: Skill 命中率（成功匹配次数 / 总触发次数）

2.【健康度评估】
  综合评分 = gate_pass_rate × 0.5 + (1 - error_rate) × 0.3 + skill_hit_rate × 0.2

  - 健康度 ≥ 80% → 正常启动，不提示
  - 健康度 60-80% → 轻量提示："📊 近期质量指标有所下降（Gate通过率 {rate}%），建议运行进化评估"
  - 健康度 < 60% → 强烈建议："⚠️ 质量指标严重下降（Gate通过率 {rate}%），强烈建议运行进化评估"

3.【自动触发条件检测】
  检查是否满足自动触发进化的条件：
  - Gate 通过率 < 85% → 建议运行进化评估
  - P0+P1 错误率 3日内上升 > 20% → 建议运行进化分析
  - 任意 Skill 命中率 < 60% → 建议改进对应 Skill

4.【数据不存在时】
  如果 ./agent_memory/logs/ 目录不存在或无近期数据：
  - 跳过健康度检查
  - 直接执行用户任务
  - 不输出任何提示

5.【检查结果记录】
  将健康度检查结果追加到当日日志：
  ### HH:MM — 健康度检查
  **执行**: 7日滑动窗口评估
  **结果**: 健康度 {score}% ({level})
  **关键指标**: Gate通过率 {rate}%, 错误率 {rate}%, Skill命中率 {rate}%
