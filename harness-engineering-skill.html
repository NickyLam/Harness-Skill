Quality Gates

7-Gate 防御纵深

每个 Gate 不通过 = 不允许进入下一阶段，支持 L1/L2/L3 严格度分级

Gate L1 Lightweight L2 Standard L3 Strict
Spec Gate 文档存在 + 审批 + ≥1 验收标准 + ≥3 验收 + 方案对比
Plan Gate 任务列表存在 ≤5min/任务 + 依赖标注 + 风险评估 + 工时估算
Build Gate 编译通过 TS + Build + ≤100行 + 安全扫描
Test Gate 测试通过 + 覆盖率 ≥80% + ≥90% + 突变测试
Review Gate 自动化检查 P0=0, P1≤3, Lint P1≤1 + 安全审查
Simplify Gate 无严重问题 函数≤50行, 文件≤500行 + 圈复杂度 ≤10
Ship Gate Git 干净 + Tag 全部门禁 + 构建成功 + 灰度计划 + 回滚预案
